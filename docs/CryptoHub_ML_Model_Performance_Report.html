3. Predictive Algorithms Implemented

1. Stacking Ensemble Regressor (Production Model) Weighted Stacking Blend
The flagship production model combines de-correlated tree bagging (Random Forest) with second-order gradient boosting (XGBoost). Instead of predicting absolute currency values that decision trees cannot extrapolate beyond historical peaks, the ensemble predicts the 1-day percentage change (Δ%), reconstructing future price boundaries dynamically.
Target Return: y = (Close_(t+1) - Close_t) / Close_t
Prediction: Δ_ens = (0.55 × Δ_RF) + (0.45 × Δ_XGB)
Reconstructed Price: P_(t+1) = Close_t × (1 + Δ_ens)
2. Random Forest Regressor (Ensemble Base Estimator) sklearn.ensemble.RandomForestRegressor
An ensemble of 350 to 450 decision trees trained with bootstrap aggregating. Each split evaluates a random subset of technical features. Excels at identifying non-linear threshold triggers (e.g., RSI < 30 combined with Bollinger lower band piercing). Configured with max_depth=10 and min_samples_leaf=2 to prevent variance expansion.
3. Extreme Gradient Boosting (XGBoost Regressor) xgboost.XGBRegressor
Constructs sequential additive decision trees that minimize a regularized objective function using exact first and second-order Taylor gradients. Uses a shrinkage learning rate (η = 0.03), column sub-sampling (0.85), and row sub-sampling (0.85) to mitigate overfitting in volatile market regimes.
4. Bidirectional LSTM Deep Neural Network TensorFlow / Keras Recurrent Model
A 2-stage recurrent architecture with forward and backward hidden states. Features a 14-day sliding lookback tensor, Dropout(0.15) regularization, and Huber Loss (Smooth L1) which prevents exploding gradients during crypto flash crashes.
Huber Loss: L_δ(y, f(x)) = 0.5(y - f(x))² for |y - f(x)| ≤ δ, else δ|y - f(x)| - 0.5δ²
5. ARIMA (AutoRegressive Integrated Moving Average) statsmodels.tsa.arima.model.ARIMA
A classical statistical time-series model parameterized as ARIMA(p=5, d=1, q=2). Operates as a linear baseline comparator against modern machine learning architectures.

4. Feature Engineering Matrix (28 Features)

Prior to inference, the raw OHLCV candle streams are transformed into a 28-dimensional quantitative tensor:

  • Autoregressive Lags (6): Close Price at t-1, t-2, t-3, t-7, t-14, t-30.
  • Moving Averages (7): Simple Moving Averages (SMA-7, 14, 30, 50) and Exponential Moving Averages (EMA-7, 14, 30).
  • Momentum & Trend (4): 14-Period RSI, MACD Line (12, 26), MACD Signal Line (9), Daily Percentage Return.
  • Volatility & Bands (5): 14-Period Rolling Std Dev, Annualized Rolling Volatility, Bollinger Upper & Lower Bands (20-period, 2σ).
  • Market Execution (4): Open, High, Low, Trading Volume.
  • Calendar Cyclicals (2): Day of the Week (0–6), Month of the Year (1–12).

5. Algorithmic Trade Decision Engine

The projected delta is combined with a composite scoring algorithm to generate the final signal:

Signal Score = (0.40 × ML Projected Move) + (0.25 × RSI Momentum) + (0.20 × News Sentiment Polarity) + (0.15 × Volatility Penalty)
Recommendation: BUY if Score ≥ 65 | SELL if Score ≤ 35 | HOLD if 35 < Score < 65
